# Bookapp

Una biblioteca personal donde podés ver las portadas de tus libros favoritos, buscar nuevos títulos y calificarlos con estrellas.

---

## ¿Qué es este proyecto?

Bookapp es una página web hecha con **Astro** que funciona como una biblioteca visual. Muestra portadas de libros en una grilla, te permite buscar cualquier libro del mundo y agregarle una puntuación de 1 a 5 estrellas.

---

## ¿Qué tecnologías usa?

- **Astro** — el framework con el que está construida la página
- **HTML y CSS** — para la estructura y el diseño visual
- **JavaScript** — para la interactividad (estrellas y buscador)
- **Open Library API** — una API gratuita que provee información y portadas de libros de todo el mundo

---

## ¿Qué funcionalidades tiene?

- Grilla de 14 portadas de libros organizadas en 2 filas de 7
- Estrellas interactivas debajo de cada portada para darle puntaje
- Buscador conectado a la API de Open Library que agrega nuevos libros a la grilla
- Diseño responsive: se adapta a tablets (3 columnas) y celulares (2 columnas)
- Header con logo y buscador centrado
- Footer con mi nombre
